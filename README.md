# Elite Cut BarberShop

Landing page moderna y responsive para una barbería premium.

## 🚀 Demo

🔗 https://elite-cut-barbershop.vercel.app

---

## 📌 Características

- Diseño moderno y elegante
- Responsive para móviles y tablets
- Menú hamburguesa
- Animaciones suaves
- Reservas por WhatsApp
- Navbar dinámica
- Galería interactiva

---

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

---

## 📱 Responsive Design

La página está optimizada para:

- Desktop
- Tablets
- Smartphones
